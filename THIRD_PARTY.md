# Third-Party Research and Attribution

The project studies public CK3 modding documentation and prior Workshop mods to understand feasible implementation patterns.

## Reference projects

- Silk Road — prior `My dynasty` map-mode precedent.
- Family Matters — credits/reuses Dynasty Map Mode concepts from Silk Road.
- War Maps / War Maps 3 — custom static map modes and practical notes about barony color effects.

## Policy

- Prefer reimplementation from documented behavior and current CK3 APIs.
- Do not copy third-party code into this repository unless its license/reuse terms permit it.
- If code is reused, record exact source, author, license/permission and modified files here before merging.
- Workshop descriptions that request attribution must be honored even when reuse is permitted.
