# Security Policy

## Supported Versions

This project is in pre-implementation development and has no released versions. Security reports are welcome for the latest code on the default branch. Older commits and third-party software, including Crusader Kings III, are outside this project's maintenance scope.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting for this repository, if available, or contact the maintainer through the private contact method listed on their GitHub profile. Do not open a public issue or pull request with exploit details.

Include the affected commit or file, steps to reproduce, the impact you believe is possible, and any relevant logs or screenshots after removing personal information, local paths, and unrelated game data. Avoid attaching save files or extracted game files unless the maintainer requests them through a private channel.

## Response Expectations

The maintainer will make a reasonable effort to acknowledge a report within seven days and provide updates as the issue is reviewed. There is no guaranteed fix or release timeline. Please allow time to investigate and coordinate disclosure before publishing details. If a report is outside this repository's control, the maintainer may direct you to the relevant project or vendor.
